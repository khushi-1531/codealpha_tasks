## Completed Tasks

### Data Science

#### [Task 1 — Iris Flower Classification](DataScience/Task1_Iris_Flower_Classification/)
* **Status:** **Completed & Audited (25/25 Tests Passing)**
* **Domain:** Supervised Machine Learning / Multiclass Classification
* **Objective:** Classify Iris flower specimens into three species (*Iris setosa*, *Iris versicolor*, and *Iris virginica*) based on physical morphological measurements (sepal length, sepal width, petal length, petal width).
* **Technologies Used:** Python 3.13, Scikit-learn, Pandas, NumPy, Matplotlib, Seaborn.
* **Architecture:** StandardScaler + LogisticRegression pipeline selected via 5-fold stratified cross-validation on training data (**95.83% CV accuracy**).
* **Test Performance:** **93.33% Accuracy**, **0.9333 Macro Precision/Recall/F1** on untouched 30-sample stratified test set with zero data leakage.
